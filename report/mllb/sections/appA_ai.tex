\subsection*{Workflow}

The code was co-developed with Claude (Anthropic) working on the project folder through the Claude
desktop app. The division of work was fixed from the start: the author defined the dataset, the tasks,
the models and the validation protocol (listed in \texttt{docs/\allowbreak{}DECISIONS.\allowbreak{}md} with their justification);
the assistant wrote the code stage by stage, executed every notebook in a clean copy of the repository
and inspected every figure before delivering it; the author ran each notebook on her own computer, and
the assistant compared the resulting JSON summaries with its own run, value by value, before the next
stage. Every exchange that shaped the code is recorded in \texttt{docs/\allowbreak{}AI\_\allowbreak{}USAGE\_\allowbreak{}LOG.\allowbreak{}md}.

\subsection*{Errors detected (candidates for the AI Error Bounty)}

All of them were produced by the assistant and caught by the verification loop before delivery.

\begin{enumerate}
  \item \textbf{Non-reproducible results.} \texttt{LogisticRegression(solver="liblinear")} was created
        without \texttt{random\_state}; \texttt{liblinear} shuffles the data, so two runs chose different
        hyperparameters in the outer folds. \emph{Detection}: comparing two runs. \emph{Fix}:
        \texttt{random\_state=42}; two complete runs then gave identical out-of-fold probabilities.
  \item \textbf{Silent NaN in the regression diagnostics.} The summary reported ``maximum Cook's
        distance = nan''. \emph{Cause}: one race category has a single patient, so its one-hot column
        gives that patient leverage 1, the model fits it exactly, and the standardised residual is 0/0.
        \emph{Fix}: detect leverage-1 patients, report them and exclude them from the diagnostics.
  \item \textbf{Distorted biplot.} The loading arrows were scaled with a different factor on each axis,
        which changes their directions. \emph{Detection}: arrows missing from the scaled biplot.
        \emph{Fix}: one common factor.
  \item \textbf{Misleading tree figures.} sklearn's default colours painted LGG in orange and GBM in
        blue, the opposite of every other figure; and with zero decimals the split ``IDH1 $\leq$ 0.5''
        was printed as ``IDH1 $\leq$ 0.0''. \emph{Detection}: comparing the figure with the text export of
        the tree. \emph{Fix}: recolouring and one decimal.
  \item \textbf{Axis hiding data.} The number of mutations per patient was drawn on a categorical axis
        that silently skipped empty categories, hiding the few patients with many mutations.
        \emph{Fix}: grouped ``6+'' category.
  \item \textbf{Escaping errors in generated tables} (\texttt{\$\textbackslash pm\$} printed literally)
        and minor bugs (a negative error-bar length from floating-point rounding, a lost column name,
        NumPy~2 number formatting) found when executing the notebooks.
  \item \textbf{Unreadable SHAP plots.} The first SHAP summary plots coloured the input value with the
        project's sequential palette, whose lowest value is almost white: the patients without a
        mutation (the majority) were invisible, and a long label overlapped the neighbouring panel.
        \emph{Detection}: inspecting the figure. \emph{Fix}: a grey-to-violet scale and shorter labels.
  \item \textbf{Dependency pinning.} Installing \texttt{shap} without pins pulled the newest
        \texttt{numba}, whose compatibility with the pinned NumPy~2.2 was not established.
        \emph{Fix}: \texttt{shap}, \texttt{numba} and \texttt{llvmlite} pinned to versions tested together
        (\texttt{requirements.\allowbreak{}txt}), and the additivity of the SHAP values checked in the notebook
        (maximum error below $10^{-5}$).
\end{enumerate}

\subsection*{AI Error Bounty sheets}

The strongest errors are documented below in the format of the course guideline. They were found in
the verification loop described above (second runs, figures read against the numbers, results compared
between two computers); each check is reproduced by the author from the steps in
\texttt{docs/\allowbreak{}BOUNTY\_\allowbreak{}CHECKS.\allowbreak{}md}.

\subsubsection*{Sheet C1. Non-reproducible tuning: an unseeded solver}
\begin{description}[style=nextline, leftmargin=1.2em]
  \item[Prompt] Classification notebook: nested cross-validation (10 stratified outer folds, 3 inner)
        with penalised logistic regression (L1/L2) among other models, seed 42 everywhere.
  \item[Faulty code] \texttt{LogisticRegression(solver="liblinear", max\_\allowbreak{}iter=5000)}, without
        \texttt{random\_state}.
  \item[Proof] \texttt{liblinear} shuffles the data internally. Two runs of the same notebook gave
        different out-of-fold probabilities, and in the first observed case different penalties and
        values of $C$ in some outer folds, so every number derived from them could change between runs. A single run cannot reveal it.
  \item[Correction] \texttt{random\_\allowbreak{}state=config.\allowbreak{}SEED}; two complete runs then gave identical
        out-of-fold probabilities, and the author's run on her computer reproduced every JSON value.
  \item[Reproduction] \todoverify{author: run the check in docs/BOUNTY\_CHECKS.md}
  \item[Reflection] ``Seed 42 everywhere'' is a promise that every random component must keep; an
        estimator with hidden randomness breaks it silently.
\end{description}

\subsubsection*{Sheet C2. A silent NaN in the regression diagnostics}
\begin{description}[style=nextline, leftmargin=1.2em]
  \item[Prompt] Regression notebook: multiple linear regression with residual diagnostics (course
        Chapter~3: outliers, high-leverage points).
  \item[Faulty output] The summary reported ``maximum Cook's distance = nan'', and the diagnostic plot
        silently dropped one patient.
  \item[Proof] The only American Indian or Alaska Native patient makes a one-hot column equal to 1 for a
        single row, so its leverage is exactly 1: the model fits that patient exactly and the
        standardised residual is $0/0$. statsmodels only printed a warning (``invalid value encountered
        in sqrt''), and \texttt{max()} propagated the NaN.
  \item[Correction] Leverage-1 patients are detected, reported and excluded from the diagnostic plots;
        the coefficient of that category is reported as meaningless in the PRDL report.
  \item[Reproduction] \todoverify{author: run the check in docs/BOUNTY\_CHECKS.md}
  \item[Reflection] A NaN is a result to explain, not a value to format: here it was the theory of
        high-leverage points appearing in the data.
\end{description}

\subsubsection*{Sheet C3. A tree figure that states the wrong rule and the wrong classes}
\begin{description}[style=nextline, leftmargin=1.2em]
  \item[Prompt] Classification notebook: pruned decision tree, visualised.
  \item[Faulty output] \texttt{plot\_\allowbreak{}tree(filled=True, precision=0)} painted LGG in orange and GBM in
        blue, the opposite of every other figure, and printed the first split as
        ``IDH1 $\leq$ 0.0''.
  \item[Proof] Reading the figure against \texttt{export\_text}, which gives the threshold 0.5 (IDH1 is
        0 or 1, so the split is mutated vs not mutated); the class order of sklearn's colour map was
        checked against the node sample counts.
  \item[Correction] \texttt{plotting.\allowbreak{}recolor\_\allowbreak{}tree} repaints the boxes with the project colours, and
        the threshold is printed with one decimal.
  \item[Reproduction] \todoverify{author: run the check in docs/BOUNTY\_CHECKS.md}
  \item[Reflection] A figure is part of the result: a wrong colour or a rounded threshold changes what
        the reader concludes, and no test detects it.
\end{description}

\subsection*{Reflection}

The assistant wrote code that ran without errors and looked plausible in every one of these cases; the
errors were only visible by running the code twice, reading the figures against the numbers, or
connecting a NaN with the theory of high-leverage points. Owning the code meant owning this
verification loop.
